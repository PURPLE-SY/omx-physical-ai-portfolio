# 내가 수행한 역할 (2026-10 ~ 2026-11)

작성: **PURPLE-SY (김승용)**

팀 프로젝트(OMX 모방학습)에서 내가 직접 맡은 일만 적었다. 팀 저장소의 다른 팀원 코드는 포함하지 않는다.

## 데이터 수집 운영
- 왼팔·오른팔·앞팔·양팔 텔레옵 녹화를 운영했다. 녹화 이름 규칙은 `F0N`=층, `S0N`=자리, `_EX`=분류 장소
- 텔레옵 원본 85개 폴더 / 1,085 에피소드 / 706,919 프레임(10/29–11/25, 중복 제외)
  - 근거: [data-collection-timeline.md](data-collection-timeline.md)
- Hugging Face(Purple-SY)에 원본을 정리했다
  - 기존 78쌍은 로컬과 SHA-256 전부 일치함을 확인
  - 누락 10개(텔레옵 원본 39 ep + 진단 녹화 1 ep)를 비공개로 추가하고 102/102 일치를 확인

## 데이터 품질 관리
- 11/14 시간축 압축(30 Hz 표기 ↔ 실제 13–15 Hz)을 분석했다. 원본은 보존
- Left F02 손목 action 오프셋(51.4–55.3)을 찾아냈다
  - 보정본 60 ep / 35,748 frames를 원본과 프레임 단위로 검증
  - 녹화 코드에 불일치 경고·중단 기능 추가(팀 저장소 커밋, 본인 커밋)
- 11-23·11-24 전체 품질 재검증(305 ep 분류), 해시 기록

## 학습 데이터 준비와 결과 관리
- 13k 학습용 데이터 합본과 QC 기록을 준비하고, 학습은 GPU PC에서 진행했다
- 13k 모델 7종(189파일, 8.05 GB)을 HF 업로드하고 감사했다

## 실물 검증과 안전
- 실행 전 읽기 전용 점검(preflight), 학습 범위 ±8 관절 제한, 2단계 park 순서를 적용했다
- 고정 게인 누락을 발견해 수정 요청했고, 실물 로그로 확인했다
- 실물 검증 3건(F01 S03, F02 S01 리플레이, F02 S05)에 대해 성공·실패를 원본 기록 그대로 집계했다
- 위험 상황(F02 S05 bottom 카메라 보정 실행)은 즉시 중단하고 원상 복구했다

## 팀 저장소 기여 (코드는 비공개 팀 저장소에 있어 공개본에 포함하지 않음)
- 현재 앱 저장소 본인 커밋 7건(2026-11-22–11-25)
  - 녹화 설정 이식: 게인 고정, 상대 추종, 손목 턴 보존
  - 손목 action 감시와 안전 중단
  - 팔로워 Return_Delay_Time 50 적용: sync-read 0.5초 멈춤 감소
  - 손목 목표 선행 허용
  - 오프라인 Auto Homing 2건 (미병합 브랜치)
- 이전 저장소 본인 커밋 8건(2026-10-26–11-17). 그중 기능·수정은 3건이고, 나머지 5건은 작업 보존용(stash 3, wip 1, 병합 1)
  - 모터 ID로 리더/팔로워 포트 자동 감지
  - 현재 자세 기준 상대 추종 수정 2건
  - 작업 트리 보존·병합

## AI 도구 활용 방식
- 분석·점검 스크립트 다수는 Claude Code·Codex에 지시하고 결과를 검토해 만들었다
- 실물 구동, 한도 변경, 토크 조작은 매번 직접 승인했다
