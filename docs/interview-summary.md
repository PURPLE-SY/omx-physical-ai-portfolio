# 면접용 요약

**한 줄:** 로봇 팔 모방학습(ACT)용 데이터를 1,085 에피소드 수집했다. 데이터 오류(시간축 압축, 손목 오프셋)를 원본 보존 원칙으로 찾아내 보정했고, 실물 검증 결과를 성공·실패 그대로 기록했다.

## 예상 질문과 근거 있는 답
- **데이터는 얼마나 모았나?**
  - 텔레옵 원본 85개 폴더, 1,085 ep, 706,919 frames(10/29~11/25)
  - 로컬과 HF를 대조해 중복 없이 집계했다
- **가장 어려웠던 데이터 문제는?**
  - Left F02 손목 action이 state와 51~55 어긋나 모델 첫 손목 명령이 +151 틀어진 것
  - 폴더별 정수 오프셋을 찾아 보정했다. 결과: \|a−s\| 중앙값 145→0.3, 경계 점프 49→0
  - 보정본을 다시 학습했고, 보정 데이터 리플레이로 실물 재현성을 확인했다
- **ACT 학습 결과는?**
  - 13k 모델 7종, val loss 0.21~0.33
  - loss와 실물 성공률은 별개라서 실물로 따로 검증했다
- **실물 결과는?**
  - F01 S03: 15회 중 놓기 성공 4, 완전 성공 1
  - F02 S05: 보정 없는 설정 7회 중 깨끗한 성공 4, 충돌 3
  - F02 S01: 데이터 리플레이 1회 성공(정책 추론 아님)
- **실패에서 배운 점은?**
  - 카메라 구도 보정 사본이 오히려 위험한 동작을 만들었다 → 즉시 중단하고 원복
  - 검증 안 된 보정은 실물에 바로 쓰지 않는다는 원칙을 세웠다
  - 복귀 중 충돌은 shoulder_lift 추종 지연이 원인 후보지만 아직 확정하지 못했다
- **안전은 어떻게 관리했나?**
  - 실행 전 읽기 전용 점검, 학습 범위 관절 제한, park 순서, 고정 PID 확인 로그
  - 한도·토크 변경은 사람이 승인했다
